# 忠勇山步道｜碧山巖往返

## 名單狀態

## 路線概覽
- **起終點**：碧山巖停車場。
- **路線**：停車場 → 碧山巖旁石階／忠勇山步道指標 → 忠勇山山頂銅像與拓印臺 → 原路返回停車場。
- **型態**：短程上坡往返；主要挑戰是連續石階與上坡。路線為依公開步道資料整理，未持有本路線 GPX，因此不列精確公里數及累積爬升；現場按「忠勇山」指標行走。
- 山頂可看市景；忠勇山越嶺步道可續下接金龍產業道路，但若停車於碧山巖，建議原路折返，避免走成不同終點的單程路線。

## 路線分段
1. **停車場 → 碧山巖側登山階梯**：停妥後依現場「忠勇山」步道指標前進。先在平坦處整理裝備、補水及使用洗手間（開放情形依現場）。
2. **登山階梯 → 忠勇山山頂**：循石階上行，經忠勇亭及山頂銅像一帶至拓印臺。途中在安全寬處休息；階梯濕滑或負重不穩時停止上行。
3. **忠勇山山頂 → 原路回停車場**：依原路下階梯返回。下坡放慢腳步，不超越或在階梯上停留拍照。

## 停車與交通
- **自駕**：導航「碧山巖開漳聖王廟／碧山巖停車場」，地址為臺北市內湖區碧山路24號。碧山巖周邊有多處停車區，依現場停車標示選擇；假日及賞花旺季車位較緊張，不預設一定有位。
- 停車費率、格位數及各停車區開放時間：本次未從官方資料確認，依現場公告為準。
- **大眾運輸**：可搭小2至「碧山巖（白石湖）」站，班次出發前查臺北市公車動態；由站牌依指標步行到廟區及步道入口。
- [導航至碧山巖](https://www.google.com/maps/search/?api=1&query=%E7%A2%A7%E5%B1%B1%E5%B7%96%E9%96%8B%E6%BC%B3%E8%81%96%E7%8E%8B%E5%BB%9F)

## 親子與安全
- 路線有連續石階及上坡，不適合嬰兒車；幼兒由成人背負時，先確認背巾／背架符合產品規範，並評估成人負重、上下階梯能力及幼兒當日狀況。
- 石階遇雨、潮濕或青苔時容易滑倒；不建議雨天或雨後路面未乾時背負幼兒上行。成人或幼兒不適即原路折返。
- 不在階梯、步道邊緣及墓園範圍逗留；垃圾自行帶下山。
- 安排實際行程時，依活動日期重新評估幼兒年齡、裝備、休息與照護需求；本口袋名單不固定年齡快照。

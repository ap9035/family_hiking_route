## 路線概覽
- **官方步道主線**：福隆山步道全長約1.315公里，分兩段，中間由凌雲路隔開；終點在凌雲禪寺。官方資料指出可由凌雲禪寺續接尖山步道，再往鷹仔尖山及尖山連峰。
- **登鷹仔尖方向**：福隆山步道 → 凌雲禪寺 → 依現場指標及離線軌跡接尖山步道 → 鷹仔尖（434公尺）→ 原路折返。此段山徑岔路較多，未找到官方公布的登頂里程／爬升，不臆列精確數字；出發前下載與當日路況相符的GPX，依現場標示核對。
- **路況重點**：福隆山古道段以石階為主；尖山支線部分路段為陡坡、土徑及拉繩路段，雨後濕滑時不續行。岔路依現場標示及離線GPX核對。
- **延伸環線參考**：有山友紀錄以福隆山步道、小北插、鷹仔尖、潮音洞及尖山步道完成約2.97公里、爬升約204公尺、約2小時43分的環線；為單次GPX紀錄，非官方路線數據。

## 路線安排
1. **起點 → 福隆山步道**：橘20「觀音山」站附近下車，依現場步道標示前往福隆山步道入口；官方交通資料列由站牌步行約0.2公里。入口地址在官方不同頁面分別標示凌雲路三段41號或86號旁，現場以「福隆山步道」指標為準。
2. **福隆山步道 → 凌雲禪寺**：步道分兩段，中間需走一段凌雲路；路線資料描述首段約400公尺、道路銜接約700公尺，之後接第二段至凌雲禪寺。
3. **凌雲禪寺 → 鷹仔尖 → 原路返回**：依尖山步道及鷹仔尖方向的現場指標、離線GPX行進；尖山支線路況與岔路以現場為準。

## 停車與交通
- **大眾運輸**：捷運蘆洲站轉乘橘20至「觀音山」站，再依指標步行至福隆山步道入口；也可搭至「凌雲禪寺」後步行接近上段。橘20班次與停靠站會變動，出發前查新北市公車動態。
- **自駕**：觀音山區停車空間有限。官方資料提及凌雲寺前方曾開放廣場供小客車停放；現行開放、收費及空位未核實，依當日現場標示及管理單位公告為準，不將歷史免費資訊視為現況。

## 行前確認
- 查官方步道公告與天候；雨後土徑、拉繩段濕滑時不走鷹仔尖支線。
- 確認尖山步道岔路及橘20班次；停車狀況依現場公告。

## 已知條件
- 出發地與健行後安排：每次行程另行確認，不存入目的地筆記。
- 交通方案：開車停天母，實際成行前重新確認。
- 健行目標：天母側上山走到文化大學，中途希望順訪翠峰瀑布，再原路返回天母取車。瀑布支線另外評估，不是必達點。
- 健行後安排每次另行確認，不預設固定續排行程。
- 同行以根目錄共用筆記及當次確認為準；不在口袋名單固定小孩年齡。另見[家庭資料](../../共用筆記.md)。
- 活動日期、出發時間及小孩活動當日年齡：下次安排時確認與重算。

## 目前規劃
- 開車至天母停車 → 中山北路七段232巷登山口 → 黑色大水管 → 自在亭 → 打印台 → 翠峰瀑布支線往返（條件允許才走）→ 回主線經翠峰亭一帶 → 愛富三街上端出口／陽明天主堂一帶 → 文化大學 → 原主線下山 → 天母取車。
- 文化大學側「古道出口」不等於已進到校園；另留街道步行時間。校園是否開放、公廁是否可使用須現場確認。
- 帶嬰兒負重、休息與餵食，停車至取車先保留約5–7小時彈性，非實測保證；不再以先前3–4小時停車預算當整趟時間。

## 詳細路線（主線重開後才適用）
### 1. 停車場 → 中山北路七段232巷登山口
- 天母公園停車後，依步行導航接中山北路七段，再往七段北端／232巷的「天母古道親山步道」入口，約10–15分鐘粗估；西側地下停車場約20–25分鐘粗估。
- 導航要選天母側入口，不是文化大學側入口。抵達時拍下入口導覽圖與開放告示，核對主線、打印台及上端出口位置。
- 起登前完成換尿布、餵食及背負裝備檢查；不要預設登山口有可用廁所。

### 2. 天母登山口 → 黑色大水管 → 自在亭
- 沿水管路主線的連續石階往上爬。經民宅與中途車道銜接處，仍循「天母古道／自在亭／文化大學」方向，不沿車道改走其他步道。
- 黑色大水管是主要地標，繼續上行至自在亭。不要攀爬水管拍照。
- 帶嬰兒負重可先抓45–75分鐘（含短休，規劃粗估）；這是去程主要爬升段，不照一般遊記的快走時間趕路。
- 自在亭停10–15分鐘檢查成人負重與嬰兒狀況。若已明顯疲累或地面濕滑，就在此折返，不勉強走到校園。

### 3. 自在亭 → 較平緩主線 → 打印台
- 自在亭附近岔路循「文化大學／天母古道」指標續行；從天母上來的舊遊記記為取左，不誤入往光華路的車道。以當日指標、入口圖與離線地圖交叉核對。
- 進入較平緩的林蔭碎石步道，前往打印台（亦有資料稱拓印亭／拓印台）一帶。先抓25–40分鐘步行粗估。
- 此區可能遇獼猴；保持距離，不餵食、不接觸，收好食物與塑膠袋。餵小孩前先找無猴群干擾的位置。

### 4. 打印台 → 翠峰瀑布 → 原支線回打印台（非必走）
- 想看的瀑布先按「翠峰瀑布」規劃，不與水源管制區內的文大瀑布／其他瀑布混淆。
- 舊遊記指出打印台旁有下切支線；由天母往文化大學方向行走時記為左側下階梯，之後平台岔路取右進入往瀑布山徑。不同走向的遊記左右會相反，不能只背左轉右轉。
- 下切途中會由石階變成泥土、樹根路，末段有陡坡、濕滑溪邊及輔助繩索；不是主線同等級的碎石步道。支線入口不清、指標缺失、路跡中斷、需要拉繩或踩溪石時就停止，不靠水聲探路。
- 一般成人舊遊記約單程15分鐘；規劃上另留往返與短暫停留40–60分鐘，並非帶嬰兒可安全通行的承諾。
- 攜帶嬰兒時，不建議背著嬰兒走最後的陡滑下切段或到溪床；未來需依成行當日重新計算的年齡與發展狀況再評估。建議取消瀑布，或在支線確認開放且天候、路況適宜時，由一位成人獨自短程往返，另一位成人帶小孩留在安全主線休息點；先約定聯絡與返回時間，條件不適合就全員略過。
- 下雨、近日豪雨、颱風後路況未確認、溪水大或現場封閉，瀑布一律取消。不得翻越封鎖線、涉水、攀岩或讓嬰兒落地在溪邊活動。
- 看完原支線回打印台，再走主線往文化大學；不沿溪續行，也不走猴洞產業道路的O形回程。

### 5. 打印台／翠峰亭一帶 → 愛富三街上端出口
- 回到主線後繼續循「文化大學」方向，經翠峰亭一帶續行上端階梯與竹林路段；亭體若有圍封，只走允許通行的主線，不進亭內。
- 經水源設施或鐵門，僅走公共步道；水源管制區不是前往文化大學的捷徑。
- 先抓20–35分鐘步行粗估，沿指標走出愛富三街、陽明天主堂附近的上端出口。
- 不同資料將出口巷名寫為愛富三街12巷或72巷，尚未核實地址差異；使用「天母古道文化大學側入口／陽明天主堂」作核對地標，不僅靠巷號導航。

### 6. 上端出口 → 文化大學 → 休息折返
- 出口後依步行導航，沿愛富三街及華岡路一帶公共道路往中國文化大學校區方向走；依所選校門，單程先留10–20分鐘粗估，留意人車及路口。
- 暫定以「文化大學校門／校區外圍」為到達點，不假設可以穿越校舍或任意進校。實際想去的校門、餐廳或校內地點未指定，最後街道轉彎需當日導航確認。
- 預留30–60分鐘用餐、餵食、換尿布與休息；店家、廁所與校園開放不保證。
- 以天母起登約3小時後開始回程作保守決策點；若已延誤、嬰兒不適或成人疲累，提前折返，不為了到校園再加碼。

### 7. 文化大學 → 原主線回天母 → 取車
- 先回同一個愛富三街古道出口，核對入口照片後下行，沿主線回打印台、自在亭，再沿水管路階梯下到中山北路七段232巷。
- 回程不再下切瀑布，不改走半嶺步道、翠峰步道或陌生產業道路；保留約90–150分鐘下山粗估，另加走回停車場時間。
- 背嬰兒下階梯時避免邊走邊拍照，留意腳下與重心，疲勞就停在安全寬處休息。天黑前離開步道。
- 下山取車後依當次安排返程；若成人已疲勞，先休息再開車。

## 執行條件與時間提醒
- 第一關是官方解除封閉，不是到場看見有人走就算開放；可先打臺北市1999詢問大地工程處步道狀態。
- 第二關是主線至文化大學全段可走；即使天母階梯開放，不代表上段或瀑布可通。
- 第三關是成人負重與嬰兒狀況，裝備須符合製造商對體重、頭頸控制與坐姿的規範；不使用嬰兒推車走石階山徑。
- 分段時間皆為依舊遊記調整的規劃區間，不是GPX測量；若各段都走到上限，總時間可能超過7小時，應取消瀑布或提前折返，不硬趕。

# 2026/10/25（日）｜大溝溪・鯉魚山・圓覺寺・圓覺瀑布環線（暫存規劃）

> **先確認安全再出發：** 2026/10/24查到臺北市大地工程處因薔琵颱風封閉天母古道等場域，但尚未確認本路線各段開放及災後狀況。颱風後溪谷、步道、落枝均有風險；若仍有警報、強風、下雨、封閉或路況未確認，取消戶外行程，改室內訓練。不要越過封鎖線。

## 同行與目標
- 同行以當次確認為準；私人家庭資訊不納入公開行程。
- 依使用者提供地圖，規劃大溝溪起登，繞鯉魚山、圓覺寺、圓覺瀑布後回大溝溪；有上升訓練、林蔭與溪水。只賞水，不下水、不踩溪石。
- 地圖軌跡未提供GPX檔；以下按圖判讀，方向和岔路須以現場指標／離線地圖核對，不把示意線當精確導航。

## 路線骨架與時間
參考相近 O 型 GPX：約 **3.9公里、累積爬升約240公尺**；平台記錄的行走時間約2小時量級。以下依家庭出門與步行時間一律抓一般估時兩倍，另加照護、停留與轉場，整體抓 **約5–6小時（不含車程及餐食）**。240公尺是參考軌跡而非此圖片精確值。

1. **停車 → 大溝溪園區入口**：從大湖公園地下停車場步行至大湖山莊街底、大溝溪生態治水園區入口；一般步行約10–15分，家庭排20–30分。
2. **大溝溪 → 鯉魚山登山口**：沿溪畔主步道往上游，至鯉魚山登山口／步道指標，約一般20–30分，排40–60分。入口溪谷與園區開闊段會曝曬，不是全線林蔭。
3. **鯉魚山上行 → 鯉魚山東峰／鯉魚山稜線**：依圖上紅線沿階梯、山徑上爬，循鯉魚山指標，不走往大崙頭等支線；參考軌跡約上升至223公尺一帶。一般約30–45分，排60–90分。背嬰兒時在安全平台休息，勿為趕時間加速。
4. **稜線 → 圓覺寺**：循圖示及現場指標接往圓覺寺方向下行／橫切；留意石階、濕滑及岔路。一般約20–30分，排40–60分。寺院停留、補水與換尿布另留15–25分。
5. **圓覺寺 → 圓覺瀑布**：沿圓覺寺步道依指標下行接圓覺瀑布步道。雨後或颱風後若有落石、濁水、湍急、濕滑、封閉，即取消瀑布並原路退回安全處；不靠近水邊、不涉水。一般約15–25分，排30–50分；瀑布停留10–15分。
6. **瀑布 → 大溝溪園區 → 停車場**：依圖示紅線及指標沿步道、溪畔方向回園區入口；不要為抄近路走溪床或封閉支線。一般約30–45分，排60–90分；另留停車場步行20–30分。

以上時間為保守排程範圍，不保證路況或嬰兒狀況；若落後，優先取消瀑布或提早折返，不趕路。嬰兒使用背巾／背架須符合產品身高體重與發展條件；不推嬰兒車走山徑。

## 停車
- **首選：大湖公園地下停車場**，地址成功路五段7號地下，24小時；臺北市官方資料列小型車20元／時、半小時計費。官方查詢當下總221格、剩餘32格（即時數字不代表出發時有位）。參考家庭停留5–6小時約100–120元，實際依現場公告及停留時間。
- [官方停車資訊與即時空位](https://atis.taipei.gov.tw/aspx/park/parkF.aspx?lang=zh-Hant-TW&region=%E5%85%A7%E6%B9%96%E5%8D%80&sn=TPE0888)
- 停車場到大溝溪入口步行時間需導航確認；以上排程暫留20–30分往返裕度。若滿位，現場再找合法替代停車，不停住戶出入口或紅線。

## 午餐、晚餐（依要求暫不查店家）
- 午餐：以自備簡餐／行動糧為原則，在安全、離溪岸有距離的休息點用餐；若出發太晚則改成出發前吃飽、途中補給。不要在步道邊餵食吸引猴群。
- 晚餐：健行後返程用餐；店家、預約與營業時間尚未查詢。
- 嬰兒餵奶、換尿布、安撫時間分散預留，不壓縮成一個固定短停留。

## 出發時間 ABCD（所有步行段落已按約兩倍排）
以實際離家時間為出發時間，車程依即時導航另加。因沒有起床／車程基準，為暫定切換表：

| 方案 | 離家時間 | 執行方式 | 午餐／回程 |
|---|---:|---|---|
| A | 07:30前 | 完整環線；含停車、步行、休息抓5–6小時 | 約12:30–14:00完成，簡餐後返程 |
| B | 07:30–09:00 | 完整環線但不久留；到園區後依實際進度決定是否保留瀑布 | 午餐自備，約14:00–16:00回到停車場 |
| C | 09:00–11:00 | 縮短：大溝溪上行至鯉魚山／圓覺寺擇一作折返點；不承諾瀑布及完整環線 | 午餐簡便，最晚約16:00開始回程 |
| D | 11:00後／尚未出門 | 不走完整環線、不追瀑布；改短程安全路段或取消戶外，改室內坡度訓練 | 午餐自備 |

**硬性截止：** 需預留日落前離開步道的餘裕；當日落日時間、道路交通及最新天氣另查。若官方未解除封閉或颱風後未確認安全，A/B/C全取消，D改室內。若同行者狀況不適合，按表縮短或休息。

## 出門拖延的家庭流程
- 前一晚完成背包、嬰兒用品、衣物、飲水、簡餐、停車導航；早上只留早餐、換尿布與裝車。
- 設「原定出門時間」與「最晚切換時間」兩個鬧鐘；超過原定時間不硬催，直接按 ABCD 切方案。
- 每次確認實際離家時間後再選方案；不可把晚出門的完整線硬塞進較短日照。

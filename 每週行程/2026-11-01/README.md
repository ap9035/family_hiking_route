# 2026/11/01（日）坪頂古圳＋大崎頭環線｜行程草案

> **安全先決：** 坪頂古圳的田尾仔橋、桃仔腳橋列在陽明山國家公園「具潛在危險地區」，標示水流湍急。遇水位高、水流急、橋面封閉、近期大雨或現場警示，**不過橋、不涉水、不踩溪石，立即原路退回或取消**；不可為完成環線另找未確認捷徑。步道開放與颱風後路況須於出發前重新確認。
>
> **目前預報（10/25查詢）：** 氣象署對11/1預報為白天晴時多雲、23–28°C，晚間多雲短暫雨；仍屬一週前預報，會變動。路面若濕滑、溪水增漲或發布警特報，取消跨橋環線。紫外線預報高量級，需防曬補水。

## 同行與目標
- **集合時間：** 09:00；領隊尚未通知確切集合點，以下時間暫以至善路三段370巷／坪頂古圳步道口一帶為基準。收到集合地點後，按當日導航重算離家時間。
- **同行：** 兩位成人、一位幼兒；幼兒由成人使用符合產品規範的背巾／背架背負。年齡快照只保留於本機私密文件，不放入公開行程。
- **目標：** 走訪坪頂三圳、清風亭與梯田，完成約2.3公里短環線；不延伸至擎天崗或瑪礁古道。
- **路線狀態：** 依既有示意圖安排，未取得本次路線 GPX，不列累積爬升精確值；岔路與接線按現場指標核對。

## 路線總覽與時間
![坪頂古圳與大崎頭環線路線示意](坪頂古圳-路線示意.svg)

本圖是專案自繪的路線關係示意，非比例、非導航圖。環線約2.3公里為既有導覽估值，並非GPX實測；一般步行約1小時20分至1小時45分，實際依路面、集合及團體速度調整。

**家庭保守排程：** 一般步行時間乘以2，含停車點往返步道口預留約2小時40分至3小時30分；另加幼兒照護及休息45–60分、自備餐30–45分，從開始步行到回到集合點約4–5小時15分。這是排程裕度，不是步道實測時間。

1. **停車／公車站 → 至善路三段370巷登山口：** 一般步行約10–15分；家庭排程20–30分。依現場指標走，不把車開進狹窄巷道。
2. **登山口 → 田尾仔橋 → 桃仔腳橋：** 一般約15–20分；家庭排程30–40分。石階、濕滑路段放慢，橋前先看水位與管制牌。
3. **橋區 → 登峰圳、坪頂新圳、坪頂古圳 → 清風亭：** 一般約25–30分；家庭排程50–60分。沿既有步道行走，不觸碰圳水、不跨越護欄或封鎖線。
4. **清風亭 → 大崎頭步道 → 梯田景觀 → 回至善路：** 一般約20–25分；家庭排程40–50分。大崎頭石階較陡，前段曝曬；若濕滑或幼兒背負不穩，原路折返，不勉強走完環線。
5. **回至善路 → 集合／停車處：** 一般約10–15分；家庭排程20–30分，依當日停車位置調整。

以上各段為依示意路線拆分的粗估，不能視為精確導航；岔路按現場標示確認。橋梁及水位是本路線的主要安全關卡。

## 交通與停車
- **自駕（暫定）：** 導航至至善路三段336巷路口／坪頂古圳步道口一帶；停車及集合點尚未獲官方確認。步道附近沒有可保證的正式停車位，社群步道資料亦提醒路邊車位有限；只停合法格位，不阻擋住戶出入口或道路。若無合法車位，不在巷內等候或違停，改搭公車／取消。
- [步道口地圖（Google Maps）](https://maps.app.goo.gl/JiGxB3g3jxTM6xvKA)；不需把車開進370巷。即時車位、路況與費率不保證，出發前確認。
- **大眾運輸備案：** 臺北市小18由捷運劍潭站往聖人瀑布，停靠「坪頂古圳步道口」。官方週日班表含07:30、08:00等班次；車程及到站時間依當日路況，請用公車動態確認，並預留步行至集合點時間。班表資料查核日2026-10-25。

## 餐食與裝備
- 早餐在出門前吃；午餐與幼兒食物自備，預留30–45分，在安全、乾燥且不妨礙通行處用餐，遠離水圳及橋面。
- 防滑健行鞋、飲水、雨具、防曬、簡便午餐、幼兒背負裝備、換洗衣物及個人藥品。幼兒不使用嬰兒車；成人依裝備規範確認尺寸、承重與固定，保留餵食、換尿布及安撫時間。

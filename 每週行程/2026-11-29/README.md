# 2026/11/29（日）永和運動中心攀岩｜上攀體驗行程草案

> **安全提醒：** 本行程按「上攀體驗／頂繩，由教練確保」規劃，不是自行確保或先鋒攀登。自行上攀須有場館認可的安檢卡及確保資格；未具資格者不得操作確保器。預約、教練及裝備安排須先向場館確認，未確認不自行上牆。

## 同行與目標
- **活動日期：** 2026-11-29（星期日）。
- **集合時間／預約時段：** 待確認；場館資料列週日營業09:00–22:00，實際體驗仍須預約並以場館回覆為準。
- **地點：** 永和國民運動中心6樓攀岩場（新北市永和區永利路250號）。
- **同行預設：** 兩位成人、一位幼兒，實際同行待確認。幼兒活動日年齡僅寫入本機私密 Word，不放入公開 Markdown。<!-- WORD_PRIVATE_CHILD_AGE -->
- **目標：** 成人體驗頂繩上攀；官方場館資訊列體驗含教練指導及教練確保，約1小時、最多3次完攀，裝備依預約方案確認。
- 若幼兒同行，**幼兒不安排攀登**；必須有一位成人在地面專責照看，不能讓照顧者同時攀爬或確保。以兩大一小參加時，只有在場館同意並有教練確保的安排下，兩位成人輪流體驗；如需兩人同時攀登，另安排照顧者或不帶幼兒同行。

## 活動與時間
- 上攀為繩索保護活動，攀登者穿吊帶，由符合場館要求的教練／確保者操作繩索與確保器；不要把「上攀」當成抱石或自行上牆。
- 體驗課程約1小時；另預留報到、裝備穿戴、熱身及收拾約30–60分鐘，總停留先抓 **1.5–2小時**，實際依預約場次及現場流程調整。
- 預約時確認成人可參加人數、幼兒是否可入場／旁觀、現場照護空間、是否需自備或租借攀岩鞋，以及未持安檢卡者的教練確保流程。

## ABCD 延誤方案（依實際離家時間）
以預約開始時間 **M**、當日門到門導航時間 **T** 換算。攀岩體驗請先準時報到，不以遲到後自行補爬為預設。

| 方案 | 目標抵達／離家換算 | 執行內容 | 處理方式 |
|---|---|---|---|
| A | M−15分鐘前抵達；離家不晚於 M−15分−T | 完成報到、穿戴裝備及安全說明，再由教練帶領上攀體驗。 | 預留1.5–2小時場館時間。 |
| B | M−15至M抵達；離家約 M−15分−T 至 M−T | 先聯絡場館確認仍可參加，不略過安全說明。 | 依場館安排縮短或改時段。 |
| C | 預計 M後抵達 | 不自行上牆或要求跳過教練確保；先詢問是否能改到當日其他時段。 | 無場館確認就取消本次上攀。 |
| D | 無預約確認、無教練／合格確保安排、幼兒無人照看或場館不允許同行 | 不進行上攀，另約日期；不改成無人確保的攀登。 | 取消攀登活動。 |

# 每週健行

## 文件配置
- `共用筆記.md`：專案通用規劃原則；個人家庭資料請保存在本機，不要提交到公開 repo。
- `每週行程/YYYY-MM-DD/README.md`：當週目的地、路線、成行狀態與改期原因；避免記錄個資。
- `口袋名單/目的地/README.md`：不綁日期的路線、交通、停車、風險與最後查核時間；不在此固定小孩年齡。
- `口袋名單/目的地/歷史文件/`：舊版Word等歷史快照，不能視為最新出發指引。
- `.opencode/skills/`、`AGENTS.md`、`opencode.jsonc`：本專案載入指引。

## 快速入口
- [2026-10-25：天母古道取消，替代行程待定](每週行程/2026-10-25/README.md)
- [口袋名單索引](口袋名單/README.md)
- [共用規劃原則](共用筆記.md)

## 使用方式
- 安排某週時，從口袋名單挑選並在該週紀錄連結，不複製整份路線，以免多份資料不同步。
- 出發前重新查天氣、步道開放與停車費，並依當次日期重算年齡；口袋名單不是可立即成行的保證。
- 日期資料留在每週行程；地點研究更新口袋名單。Word為衍生檔，修改來源Markdown後重新匯出。

# 每週健行｜臺灣步道行程與親子健行筆記

這裡整理步道路線、交通、停車、風險提醒與每週行程紀錄。資料以 Markdown 維護，並透過 GitBook 提供閱讀導覽。

> **安全提醒：** 步道開放、天候、交通與停車資訊可能變動。出發前請查官方公告並依現場指標行走；封閉或天候不適時請勿進入。

## 開始閱讀

- [健行口袋名單](口袋名單/README.md)：按目的地整理路線與重新安排前的確認事項。
- [忠勇山步道](口袋名單/目的地/忠勇山/README.md)：碧山巖停車場起登的往返路線。
- [牛港稜山步道](口袋名單/目的地/牛港稜山/README.md)：觀音山遊客中心起登，經牛港稜山至賞鷹台往返。
- [鷹仔尖（福隆山）](口袋名單/目的地/鷹仔尖/README.md)：觀音山福隆山步道接尖山步道的路線研究。
- [三角埔頂山步道](口袋名單/目的地/三角埔頂山/README.md)：軍人忠靈祠起登，經多福步道至山頂往返。
- [2026-11-01｜坪頂古圳](每週行程/2026-11-01/README.md)：坪頂古圳與大崎頭環線行程。
- [2026-10-25｜行程紀錄](每週行程/2026-10-25/README.md)：過往行程草案與當週紀錄。

## 資料原則

- 行程與目的地資料以 Markdown 為主；Word 文件為本機衍生檔，不納入公開版本。
- 生日、住址及其他家庭個資只保存在本機私密筆記。
- 路線圖標示為示意圖時，不應作為導航依據；以官方資料及現場指標為準。
- 路線地圖可用 `python3 scripts/generate_osm_route_map.py <目的地目錄>/osm-map.json` 產生；OSM 資料會快取於 `.cache/`，需更新時加 `--refresh`。
